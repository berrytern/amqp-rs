# amqp-rs

High-performance AMQP client bindings for **Python** (PyO3) and **Node.js** (NAPI-RS), powered by [`amqp-client-rust`](https://crates.io/crates/amqp-client-rust) and Tokio.

## Packages

- **Python (`amqp-rs`)**: [bindings/python/README.md](bindings/python/README.md) — CPython 3.9–3.15 (including Free-Threaded 3.13t / 3.14t / 3.15t)
- **Node.js (`amqp-rs`)**: [bindings/node/README.md](bindings/node/README.md) — Native N-API addon with TypeScript definitions
